# my-first-app

Portfolio CV for Hosea Dwayne J. Lobo, built with Angular 22.

Components: Header, ProfileCard, Skills, Footer. `App` owns all data and passes it down with inputs;
Skills sends the selected skill back up with an output.

```bash
npm install
npm start
```

Open http://localhost:4200.

To take the "works!" screenshot, set `checkpoint = true` in `src/app/app.ts`, then set it back to `false`.
